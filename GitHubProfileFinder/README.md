# GitHub Profile Finder

A responsive web application that allows users to search for any GitHub profile and view detailed information using the GitHub REST API.

## Features

- Search GitHub users by username
- View profile information
- Display avatar, bio, company, and location
- Show followers, following, and public repositories
- Display top 5 repositories sorted by stars
- Recent searches using Local Storage
- Responsive and modern UI
- Error handling for invalid usernames

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub REST API

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Enter a GitHub username.
4. Explore the profile and repositories.
